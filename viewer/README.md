# 物語ビューア

story-creator スキルが `stories/` に作る進捗と成果物を、ブラウザで見やすく確認するためのローカルアプリです。読み取り専用で、ファイルは変更しません。

## 使い方

1. [start.cmd](start.cmd) をダブルクリックする（ブラウザが開きます）。
2. 終了するときは、開いた黒い画面で `Ctrl+C` を押すか、ウィンドウを閉じる。

アドレスは既定で **http://localhost:8765/** です。ポートが使用中のときは `start.cmd -Port 9000` のように変えられます。

追加のインストールは不要です（Windows 標準の PowerShell で動きます）。

## 見られるもの

| 画面 | 内容 |
|---|---|
| 概要・進捗 | 8フェーズの状態、**確認待ち（レビュー待ち）の一覧**、最初・結末、執筆方針、章ごとの状況、変更履歴、承認ごとのコミット履歴 |
| 各成果物 | アイデア、章構成、登場人物、相関関係図（図つき）、重要な物、章ごとの起承転結、レビュー |
| 章の本文 | 読書用の表示。縦書き、文字サイズの変更、肉付けメモの折りたたみ |
| 完成稿 | 承認済みの全章を結合した原稿 |

- ファイルが更新されると、約2秒で自動的に画面に反映されます（手動の再読み込みは不要です）。
- 左のナビの色の点は、グレー＝未着手、黄＝作成中、**青（点滅）＝あなたの確認待ち**、緑＝承認済みです。
- 各成果物の画面の「原文を表示」で、Markdown の原文を見られます。
- 承認や修正の依頼は、これまでどおり Claude のチャットで伝えてください。ビューアは表示専用です。

## 補足

- 物語が複数ある場合は、左上のプルダウンで切り替えます。
- 相関関係図は Mermaid を CDN から読み込んで描画します。オフラインのときは図のもとになる記述が表示されます（表が正なので内容は確認できます）。
- 見えるのは `stories/<物語名>/` の `.md` ファイルだけです。他の場所のファイルは配信しません。サーバーは `localhost` からのアクセスにのみ応答します。

## 構成

| ファイル | 役割 |
|---|---|
| `server.ps1` | PowerShell の小さなサーバー。`stories/` を読む API と静的ファイルを配信する |
| `public/index.html` `public/app.js` `public/style.css` | 画面。Markdown の整形も自前で行い、外部ライブラリは Mermaid だけ |
| `start.cmd` | 起動用 |
